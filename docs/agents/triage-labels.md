# Triage labels

For local Markdown tracking, use these canonical `Status:` values where triage state is needed:

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

Implementation/Wayfinder files may additionally use operational states such as `open`, `claimed`, `in-progress`, `review`, and `resolved`.
